NL-to-SQL Search Plan

Plan for a Mutual Fund Distributor Portal natural-language input box that converts distributor queries into safe, read-only SQL over approved PostgreSQL views while keeping model execution and data fully inside the data centre.

Read-only MVP API Approved views only Distributor-scoped results 3 core query families SELECT-only SQL Basic audit logs

Executive Summary

Build a small distributor search MVP that accepts natural-language business queries, maps them to a few approved read-only query patterns, applies mandatory distributor authorization, and returns paginated results with interpreted filters and simple confidence or ambiguity warnings.

Simplified MVP approach: start with a narrow query-plan contract and deterministic SQL templates. Avoid broad free-form NL-to-SQL until the first query families are validated with users.

Scope Boundaries

In Scope

  • Investor discovery: find investors by name, city, state, KYC status, and risk profile.
  • Investment amount search: find investors by total investment value and fund category.
  • SIP status search: find investors by SIP status like active, ceased, expired, or no active SIP.
  • Read-only execution against approved distributor-safe views with mandatory distributor scope.

Out of Scope

  • Transaction-level purchase/redemption analytics and complex time-series comparisons.
  • Advanced scheme inclusion/exclusion logic.
  • Complex column/table/scheme inclusion/exclusion logic.
  • Contact-field search, SQL visibility toggles, admin/global analytics, and custom report generation.

Simple MVP Costing Estimate

Approximate monthly cost range for the simplified NL-to-SQL MVP. This keeps sizing focused on early usage and the minimal AWS application infrastructure needed to run one Dockerized Search API service.

Costing assumptions: 30-day month, around 2,000 input tokens and 500 output tokens per search request, 100-1,000 requests per day, one ECS Fargate Search API service, ALB, and ECR. Existing client PostgreSQL/database cost is not included. Figures are approximate USD ranges and should be validated against the final AWS region.

What Is Included / Excluded

  • Included in ranges: AWS LLM usage, one Dockerized Search API on ECS Fargate, ALB, ECR image storage, and light logs/metrics.
  • Excluded: existing client PostgreSQL cost, VPN/Direct Connect/private link setup, enterprise support, taxes, heavy observability retention, provisioned throughput commitments, and high-volume scale testing.
  • If prompt size doubles to around 4,000 input and 1,000 output tokens, model usage costs roughly double.
Recommended cost posture: use Nova Lite as the baseline for the simple MVP if quality is acceptable. Use Claude 3 Haiku only if structured output quality is noticeably better during validation.
